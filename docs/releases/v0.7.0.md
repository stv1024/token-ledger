# TokenLedger v0.7.0

Released 2026-10-09. Adopts the Paseo 0.11 screen and sidebar APIs and fixes
Git installs on Paseo 0.11. Token accounting, stored records, and custom prices
are unchanged.

## Compatibility

Requires **Paseo >=0.11.0** on both the daemon and app, without an upper version
limit. Paseo 0.9.1-0.10.x users should stay on v0.6.3. The verified host is
**0.11.1**; the 0.11.0 plugin SDK is identical to 0.11.1. SDK development
dependencies are pinned to 0.11.1. See the [compatibility notes](../compatibility.md).

## Changes

- **Overview screen.** The overview is a Paseo 0.11 screen with Today, Last 7
  days, Last 30 days, and All time ranges. The range is a screen param, so the
  link and the header title follow it. A range lists agents with turns that
  ended in it and agents with a turn in flight. Day ranges start at local
  midnight on the device that shows them.
- **Sidebar footer row.** A TokenLedger row in the sidebar footer shows today's
  cost (or tokens when no price is known), with an activity icon while a turn
  runs. It replaces the sidebar header link and opens the overview on Today.
- **Git install fix.** On Paseo 0.11, `github:` and `git:` installs of v0.6.3
  failed with `Could not resolve type dependency "@getpaseo/client"`. Shipped
  code now derives Paseo client types from the host SDK, so `@getpaseo/client`
  and `@getpaseo/protocol` are development dependencies only.
- **Registry listing.** The manifest declares the display name, a PNG icon, and
  screenshots, and the package ships `OVERVIEW.md` for the
  [registry page](https://paseo.sh/plugins/stv1024/token-ledger).

## Install or update

Update the daemon and app to Paseo 0.11.0 or later first. Then, for an existing
npm installation:

```bash
paseo plugin update token-ledger
```

For an existing GitHub installation:

```bash
paseo plugin update token-ledger --ref v0.7.0
```

For a new installation:

```bash
paseo plugin install npm:paseo-token-ledger
# or
paseo plugin add github:stv1024/token-ledger --ref v0.7.0
```

Registry installations (`paseo plugin add stv1024/token-ledger`) receive v0.7.0
after the registry maintainers review it. Run `paseo plugin ls`; TokenLedger
should be `running`. Reopen the desktop app if a window still shows the old
sidebar link. No ledger migration or deletion is needed.

## Validation

- Typecheck and all 65 automated tests passed against the 0.11.0 and 0.11.1 SDKs.
- A copy without `node_modules`, installed as a directory, compiled both bundles
  and reached "Plugin ready".
- Reloaded on the installed Paseo 0.11.1 daemon without errors. A real Claude
  turn and a real Codex turn each produced one completed record; the Codex
  record kept two request observations.
- The registry's own manifest and overview checks accept the new metadata.
- The maintainer completed manual testing of the sidebar row and overview
  ranges before authorizing release.

Paseo 0.11.1 still omits cache-write counts and Codex provider-internal child
usage from the public accounting API. This release does not recover that data.
