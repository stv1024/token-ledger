# TokenLedger v0.8.1

Released 2026-10-23. Fixes costs for local or unbilled models that run on the
Claude Code or Codex harness through a custom provider (#1).

## Compatibility

Requires **Paseo >=0.11.0** on both the daemon and app, as in v0.8.0. Existing
`ledger.jsonl` records and `pricing.json` files are kept and are not rewritten.

## Changes

- **Custom prices override reported costs.** A new setting, off by default. When
  a `pricing.json` price matches a turn, it replaces the runtime-reported cost.
  A runtime can report a list-price fallback for a model that it does not know.
  Add `providers` to a price entry to limit it to one provider. OpenRouter and
  built-in prices never replace a reported cost. The reported value stays in
  the ledger file, so turning the setting off restores it.
- **Provider `extends`.** A custom provider that declares `extends: "claude"` or
  `extends: "codex"` in the daemon config now follows its base harness. Its
  turns get per-turn usage and prices instead of unknown-scope snapshots. New
  records store the resolved harness. Earlier records of such providers stay
  unknown-scope snapshots.

## Example

```json
{
  "version": 1,
  "currency": "USD",
  "prices": [
    { "providers": ["local-claude"], "model": "acme/local-1", "tiers": [{ "input": 0, "cacheRead": 0, "cacheWrite": 0, "output": 0 }] }
  ]
}
```

Then turn on **Settings → Plugins → token-ledger → TokenLedger → Custom prices
override reported costs**.
