# TokenLedger v0.8.2

Released 2026-10-28. Adds a shortcut to the plugin settings and moves npm
publishing to GitHub Actions.

## Compatibility

Requires **Paseo >=0.11.0** on both the daemon and app, as in v0.8.1. Existing
`ledger.jsonl` records and `pricing.json` files are kept and are not rewritten.

## Changes

- **Settings shortcut.** The overview has a gear button, and the command center
  has an **Open TokenLedger Settings** command. Both open the plugin settings
  page, which is otherwise several levels deep.
- **Published from CI.** The npm package is published by the release workflow
  with npm Trusted Publishing, so it carries provenance. No npm token is stored.
