# TokenLedger v0.9.0

Released 2026-11-18. Moves off the plugin APIs that Paseo deprecated and will
remove in April 2027. The minimum Paseo version is now 0.15.0.

## Compatibility

Requires **Paseo >=0.15.0** on both the daemon and app; verified on 0.16.1.
Before, the minimum was 0.11.0. **Paseo 0.11–0.14 users should stay on
v0.8.5**:

```bash
paseo plugin add github:stv1024/token-ledger --ref v0.8.5
```

Existing `ledger.jsonl` records, the tracker journal, and `pricing.json` files
are kept and are not rewritten. Accounting does not change.

## Changes

- **Lifecycle hooks use `addHook`.** `agent.open.before`, `agent.turn.before`,
  and `agent.turn.after` replace `server.before("agent.session_open")` and
  `server.on("agent.turn_started" | "agent.turn_ended")`, which Paseo removes
  after 2027-04-30. The hooks give the same fields that TokenLedger reads, so
  tracking works as before. `addHook` is in Paseo 0.15 and later, so this sets
  the new minimum.
- **Agent panel.** The session ledger is registered with `addAgentPanel`
  instead of `addWorkspacePanel` with `context: "agent"`, and reads the agent
  from `params.agentId`.
- **UI imports.** `Icon` and `ScrollView` come from
  `@getpaseo/plugin/client/ui` instead of `@getpaseo/plugin/client/react-native`,
  which Paseo removes after 2027-04-20.
- **Build baseline.** The SDK development dependencies are pinned to 0.15.0.
  CI checks the 0.15.0, 0.16.1, and latest SDKs.

## Verification

- Typecheck and 92 tests against the 0.15.0 pin and the 0.16.1 SDK.
- On an installed 0.16.1 daemon, a copy without `node_modules` compiled and
  loaded. `agent.open.before` ran when an agent was created and when it was
  refreshed. Both turn hooks ran for a new Claude agent, a resumed Claude agent,
  and a Codex agent, and each turn gave one `completed` record.

## Known limits

No installed 0.15 host was tested; 0.15.0 is checked by the SDK typecheck and
tests only. The overview, pill, and panel still poll for changes. Plugin
subscriptions could push them instead, but they need Paseo 0.16.
